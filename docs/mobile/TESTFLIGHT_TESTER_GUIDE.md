# Guide du testeur — Minerva Flow sur TestFlight

À envoyer au testeur avec le lien d'invitation TestFlight. Les mots de passe se transmettent à part, jamais dans ce document.

## 1. Installer l'application

1. Sur l'iPhone, installez **TestFlight** depuis l'App Store (gratuit).
2. Ouvrez le lien d'invitation reçu, puis touchez **Accepter** et **Installer**.
3. Ouvrez **Minerva Flow**. Autorisez les notifications si l'application le demande.

## 2. Se connecter

L'écran de connexion propose plusieurs modes : touchez l'onglet **Mot de passe** (pas « Continuer avec Apple » ni « Google »), saisissez l'adresse et le mot de passe fournis, puis **Se connecter**.

| Pour voir… | Adresse | Mot de passe |
| --- | --- | --- |
| **Le côté propriétaire** (gérer le restaurant) | `testeur-owner@minervaflow.app` | fourni à part |
| **Le côté client** (carte de fidélité, menu, offres) | `testeur-client@minervaflow.app` | fourni à part |

Pour passer d'un côté à l'autre : **Compte › Se déconnecter** (menu ••• en haut à droite sur la page Compte), puis reconnectez-vous avec l'autre adresse. Les deux comptes sont des comptes de démonstration : vous pouvez tout essayer sans risque.

## 3. Quoi tester

**Côté client**
- Accueil : votre solde de points, la prochaine récompense, l'historique récent.
- Offres : les offres actives et le catalogue de récompenses.
- Commander : parcourez le menu, ajoutez un plat, ouvrez le panier.
- Compte : vos cartes (une par établissement), vos favoris, votre historique de points, les notifications (choisissez « Fréquent » pour l'essayer).

**Côté propriétaire**
- Les écrans d'aperçu, de commandes, de menu et de fidélisation.
- Gestion › Mises à jour : l'historique des nouveautés.

## 4. Nous dire ce qui ne va pas

Pour chaque problème, notez : l'écran, ce que vous faisiez, ce que vous attendiez, ce qui s'est passé, et joignez une capture d'écran. Dans TestFlight, vous pouvez aussi toucher **Envoyer des commentaires** après une capture d'écran.

## 5. À savoir

- La version testée peut ne pas contenir les toutes dernières modifications : le numéro de build est affiché dans TestFlight.
- La lecture des tags NFC peut être désactivée dans cette version.
